# Fynna Montaño Portfolio — GitHub Pages

This is a static HTML/CSS/JS site. No build step is required.

## Publish / update
1. Extract this ZIP.
2. Open your existing GitHub repository.
3. Upload the contents of this folder (not the ZIP) into the repository root.
4. Choose **Commit changes** and replace existing files when prompted.
5. Keep GitHub Pages set to `main` and `/ (root)` under Settings → Pages.

The site entry point is `index.html`. The new navigation includes **Social Media** and **Guides**. The professional portrait replaces the previous About photo.

## Edit content
- `data/site.js` — name, contact details, home copy, navigation and site settings.
- `data/portfolio.js` — portfolio gallery items and categories.
- `guides.html` — execution guide content and interactive guide tabs.
- `social.html` — client brand showcase. Replace logo files in `images/logos/logos/` if needed.
- `portfolio.html` — live email campaign links and website / landing-page project links.
- `css/style.css` — visual styles. Palette: #DBDBDB, #29709D, #310004, #050505, #7D8532, plus white.

## Notes
- Client social account handles and analytics are not exposed; the brand logos are used as a showcase only.
- The email gallery uses HD previews from the supplied EDM PDF. Each card opens its matching public Mailchimp campaign URL.
- Website project cards link to the live pages supplied.
